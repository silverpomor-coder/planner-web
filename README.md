# Travel Book — вход через GitHub

Браузерный просмотр сохранённой поездки и каталога POI Италии. GitHub Pages размещает только интерфейс. Личные записи, билеты, фотографии, заметки и аудио находятся в отдельном закрытом хранилище Supabase.

## Доступ

Кнопка «Войти через GitHub» использует Supabase Auth и PKCE. Пароль вводится только на github.com. Проверка владельца выполняется на стороне базы по подтверждённой GitHub identity, а не по имени или данным, которые можно изменить в браузере. Правила Storage дополнительно закрывают файлы для остальных пользователей и анонимных запросов.

В браузерной конфигурации разрешены только URL проекта и публичный publishable/anon key. Никогда не добавляйте service_role key, secret key, OAuth client secret, исходную базу, документы или файлы поездки в этот репозиторий.

Приложение требует интернета. Личные данные не сохраняются в офлайн-кэш приложения. При выходе локально открытые сведения и изображения очищаются.

## Подключение

1. Создать отдельный бесплатный проект Supabase.
2. Выполнить `supabase/setup.sql` в его SQL Editor.
3. Включить GitHub provider, создать GitHub OAuth App и указать callback URL проекта Supabase. OAuth secret сохраняется только в Supabase.
4. Добавить адрес приложения в Supabase Authentication → URL Configuration. Для локального импорта также разрешить `http://127.0.0.1:59361/import.html`.
5. Заполнить `config.js` адресом проекта и публичным ключом.
6. Загрузить подготовленные данные в закрытый bucket `planner-private` через локальную страницу импорта после входа владельца.
7. Проверить `supabase/verify.sql`, анонимный доступ к файлам и реальный вход владельца.
8. GitHub Settings → Pages → Deploy from a branch → main → /(root) → Save.

Планируемый адрес: https://silverpomor-coder.github.io/planner-web/

## Проверка и ограничения

До заполнения конфигурации приложение показывает только форму входа с сообщением о настройке и не запрашивает файлы поездки. Неизвестные данные, не восстановленные из доступных источников, отмечены внутри поездки. Автоматической синхронизации с исходным сервером нет.

Supabase JS 2.118.0 включён локально в `vendor/`; лицензия MIT сохранена рядом. Загрузка исполняемого кода с внешнего CDN при открытии приложения не требуется.
